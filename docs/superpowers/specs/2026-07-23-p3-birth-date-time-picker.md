# P3 出生日期与时间选择器

## 目标

用项目自绘控件替换浏览器原生 `date` / `time` 输入，覆盖首次引导和“我的”资料编辑，保持固定 `960 × 640` 窗口内的 P3 神秘浪漫风格。

## 日期选择器

- 触发器显示 `YYYY/MM/DD`，未选择时显示“请选择生日”。
- 月历为周日到周六的 6 行网格，显示相邻月份日期。
- 月份标题可进入年份选择；年份按 12 年分页，选择年份后进入月份选择，再返回日期网格。
- 支持上月、下月、今天、清除；未来日期不可选。
- 选中日使用金色圆环与微光，当前日使用淡紫色标记。
- 支持 `Escape` 关闭、方向键移动日期、`PageUp/PageDown` 切月、回车选择。

## 时间选择器

- 触发器显示 `HH:mm`，未填写时显示“未填写”。
- 弹层为小时、分钟双列，小时覆盖 `00–23`，分钟覆盖 `00–59`。
- 选择过程先保留草稿，点击“完成”后更新表单；可清除可选出生时间。
- 弹层向上展开，避免超出资料卡和固定窗口底部。
- 列表支持键盘 Tab、方向键、回车选择和 `Escape` 关闭。

## 组件与数据

- `P3DatePicker.vue`：`v-model` 传递 `YYYY-MM-DD`。
- `P3TimePicker.vue`：`v-model` 传递 `HH:mm` 或空字符串。
- 页面仍由现有 profile store 保存，不改变 DTO、Tauri command 或数据库结构。
- 所有颜色、尺寸、圆角、阴影和动效从 `src/styles/tokens.css` 读取。

## 验证

- Playwright 覆盖首次引导选择生日、资料页修改生日与出生时间、清除可选时间。
- 固定 `960 × 640` 截图检查两个弹层不越界、不遮挡关键操作。
- 运行 `npm run typecheck`、`npm run test`、`npm run test:e2e`。
